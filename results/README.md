# Results and research records

These files record completed runs and decisions. Start with the
[portfolio overview](../README.md#results-at-a-glance) and
[saved examples](../docs/showcase.md), then follow the relevant source record.

| Location | Contents |
| --- | --- |
| Root JSON reports | Compact experimental outcomes, asset checks and publication/maintenance receipts |
| `protocols/` | Registered study bindings, source hashes and phase locks |
| `reviews/` | Scientific/design/code reviews and associated verification records |
| `diagnostics/` | Bounded follow-up analyses; distinct from confirmatory outcomes |
| `model_assets/` | Pinned upstream model-file metadata |
| `refusal_source_licenses/` | Retained source/license evidence |

Useful starting records: [benchmark summary](benchmark_summary.json),
[physics QLoRA](physics_prl_final.json), [7B refusal transfer](refusal_7b_transfer_01.json),
[selected benign diagnostic](refusal_7b_benign_transfer_01.json),
[7B joint traits](steering_publication_joint_04.json) and
[27B NF4 smoke](qwen38_27b_nf4_execution_01.json). The completed
[27B closeout report](qwen38_science_summary_01.json) links the quantization screen,
QASPER positive fixed-subset result, PRL experimental negative result and all four
verified Hugging Face releases. Original run receipts retain their capture-time
status; final combined reports and the release catalog describe the closeout.

Older receipts may say private, unpublished or awaiting deployment. They describe
that receipt's time; [the current release index](../releases/README.md) and
[current roadmap](../docs/project_tracks.md) describe present status. Do not edit
old results to update those labels. Add a new dated receipt for a later action.
Raw generations, judge journals, checkpoints and detailed local verification
reports are retained under ignored `outputs/` and `artifacts/`.
